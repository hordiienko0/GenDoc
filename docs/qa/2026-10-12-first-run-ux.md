## Не виправлено - пропозиції (за пріоритетом)

1. **Повна картка особи недоступна.** Імпортується 24 колонки, а в картці «Особового складу» - 7 полів.
   Дата народження, ВОС, телефон, адреси, ВЛК, посвідчення, прод. атестат не видно й не редагуються:
   помилку можна виправити лише повторним імпортом. `RecipientEditWindow` із цими полями є, але жоден
   розділ його не відкриває (`RecipientsViewModel` ніде не створюється). Пропозиція - кнопка «Усі дані…» в картці.
2. **Видалений шаблон не відновити.** Видалення м'яке, але «Кошик» шаблонів не показує, хоча пише
   «Видалені елементи можна відновити».
3. **Генерація з незаповненими полями** йде без попередження - про порожні теги видно лише після запуску.
   Варто питати до запуску («Не заповнено N полів. Згенерувати чернетки?»). Підписи `…_зв` / `…_дв`
   («Вартовий зв») новачку незрозумілі - розшифровувати як «(знах. відм.)» / «(дав. відм.)».
4. **«Завантажити теку»** обходить будь-яку теку рекурсивно й приймає .docx без жодної мітки як шаблон
   («МІТОК 0»). Випадковий вибір «Документів» завантажив два звичайні файли. Варто пропускати або
   попереджати про файли без міток.
5. **Тека документів** задається лише на екрані «Генерація» - у «Налаштуваннях» її шукають першою.
6. **Порожня база не підказує порядок дій** (набір → імпорт → шаблони → генерація). Картка набору
   «набір не сформовано» без кнопки «Імпортувати особовий склад».
7. Журнал дій: для пакета лише з груповими - «docx - згенеровано 0» (вводить в оману); колонка «Об'єкт»
