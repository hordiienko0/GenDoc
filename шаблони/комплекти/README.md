# Комплекти шаблонів

Дзеркальні шаблони, зроблені з 47 робочих документів курсового офіцера (тека `Доки`,
підтеки `стрільби`, `стрільби\обмежені`, `стрільби\придатні`). Кожен шаблон повторює
макет, шрифти, таблиці й статичний текст оригіналу; змінні дані замінено тегами `{{…}}`,
які розуміє застосунок. Шаблони згруповано в **комплекти** за робочим процесом — один
комплект = один пакет генерації в застосунку.

Перевірка: `GenDoc.Tests/Templates/KomplektTemplatesTests.cs` завантажує кожен файл через
`TemplateService.Upload` / `ExportTemplateService.UploadTemplate`, звіряє знайдені теги з
каталогом (жодного випадкового ручного тега через одруківку) і робить справжній прогін
пакета з усіма 22 шаблонами для трьох людей — у жодному згенерованому файлі не лишається `{{`.

## Як користуватися

1. **DOCX** завантажуються у «Шаблони» (документи Word), **XLSX** — у «Відомості» (Excel).
2. Зберіть пакет із шаблонів одного комплекту, оберіть набір і підписанта, заповніть ручні
   теги — застосунок пам'ятає останні введені значення, тому однакові теги в різних шаблонах
   (наприклад `{{дати_стрільб}}`, `{{номер_наказу}}`) вводяться один раз.
3. Для відомостей, що ведуться «по аркушу на кожен день стрільб», увімкніть у відомості
   «аркуш на кожну дату періоду» і задайте `{{період}}` — застосунок сам розмножить аркуш
   і підставить `{{дата_аркуша}}` (в оригіналах це були аркуші `03.08.2026`, `04.08.2026`, …).

## Типи шаблонів і теги

| Позначення | Що означає |
|---|---|
| **персональний** | DOCX без повторюваного блоку — окремий документ на кожну людину |
| **груповий** | DOCX з блоком `{{#особи}}…{{/особи}}` — один документ на весь список; всередині блоку доступні `{{номер}}`, `{{роздільник}}`, зовні — `{{кількість_осіб}}` |
| **відомість** | XLSX з рядком-шаблоном (`{{№}}`, `{{звання}}`, `{{піб}}` …) — рядок розмножується на кожну людину |

**Автоматичні теги** (заповнює застосунок з бази): людина — `{{піб}}`, `{{піб_ініціали}}`, `{{звання}}`,
`{{посада}}`, `{{підрозділ}}`, `{{особовий_номер}}`, `{{зброя}}`, `{{кімната}}`, `{{придатність}}`,
знахідний відмінок `{{піб_зв}}`, `{{звання_зв}}`, узгодження `{{прибув}}`, `{{таким}}`, відрядження
`{{дата_посвідчення}}`, `{{номер_посвідчення}}`, `{{прод_атестат}}`, оцінки `{{оцінка_1..4}}`,
`{{оцінка_загальна}}`, підпис `{{курсовий_офіцер}}`; організація — `{{номер_вч}}`, `{{назва_вч}}`,
`{{місто}}`, `{{звання_командира}}`, `{{піб_командира}}`, `{{посада_командира}}`.

**Ручні теги** (вводить офіцер перед генерацією, snake_case українською). Спільні для всіх комплектів:

| Тег | Значення | Особливість |
|---|---|---|
| `{{звання_підписанта}}`, `{{піб_підписанта}}` | підписант документа | вибирається з постійного складу (пікер «Підписант») |
| `{{дата}}`, `{{дата_рапорту}}`, `{{дата_аркуша}}` | дата документа | одне поле «Дата документа», формат `дд.мм.рррр` |
| `{{дата_прибуття}}`, `{{дата_зарахування}}`, `{{дата_вибуття}}`, `{{дата_зняття}}` | дати подій | календар, підставляється словами («01 серпня 2026 року») |
| `{{дати_стрільб}}` | перелік днів стрільб («04, 05, 06 … серпня 2026 року») | текст, один на весь комплект «Стрільби» |
| `{{номер_наказу}}`, `{{дата_наказу}}` | наказ начальника університету | той самий номер у витягу, заявці на транспорт і пояснювальній |
| `{{калібр}}`, `{{кількість_патронів}}`, `{{номер_відомості}}` | роздавальна відомість | однакові в XLSX і DOCX (форма 9а) |

Порожня пара `{{#особи}}`/`{{/особи}}` у деяких документах без списку людей (заявки, накази,
стройові записки, титул) поставлена навмисно: так шаблон генерується **один раз на пакет**, а не
на кожну людину, і в ньому працює `{{кількість_осіб}}`. У згенерованому файлі ці два абзаци зникають.

## Комплект «Стрільби»

Заявка на боєприпаси → витяг/проєкт наказу → відомість допуску (дод. 5) → залік з вимог безпеки (дод. 8)
→ роздавально-здавальна відомість (форма 9а) → заявка на транспорт → стройова записка (БЧС).

## Що свідомо не перенесено

- **Макроси** з `.xlsm` (допуск, залік, роздавальна для обмежено придатних) — застосунок працює лише з `.xlsx`; макет цих книг збігається з `.xlsx`-версіями, тому окремих шаблонів не робилося.
- **Кілька аркушів по датах** у відомостях — замінено одним аркушем «Шаблон» + режим «аркуш на кожну дату періоду».
- **Список людей у наказах** — у витягах/проєктах немає поіменного списку (він у додатку/заявці), тому тут людина впливає лише на `{{кількість_осіб}}`.
- **Форма 9а (Word)**: рядки з номерами колонок «1…16» посеред таблиці (повторювались на кожній сторінці) прибрано — лишився один рядок-заголовок і один рядок у блоці; порожні рядки таблиці не додаються, бо застосунок вставляє стільки рядків, скільки людей.
- **Стройова записка курсів**: чисельність по категоріях застосунок не рахує — теги ручні.
- Дати підписів «__ ______ 2026 року» замінено на `20__`, одруківки джерел («видачи», «інстружка», «розповсюджені») виправлено; решта тексту — як в оригіналах.
